Problem: Longest Palindromic Substring

Given a string, find the longest contiguous substring that is a palindrome.

Examples:
- "babad" -> "bab" (or "aba")
- "cbbd" -> "bb"

Requirements:
- The substring must be contiguous.
- If there are multiple longest palindromes, return any one.
- Do not use a library method that directly solves the problem.

Expected concepts:
- Strings
- Two pointers
- Palindrome checking
- Nested loops / center expansion

Approach:
Use center expansion. Every palindrome has a center. Check both odd-length and even-length palindromes around each character.

Time Complexity: O(n^2)
Space Complexity: O(1)

Python Solution:

def longest_palindromic_substring(s):
    if not s:
        return ""

    start = 0
    end = 0

    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return left + 1, right - 1

    for i in range(len(s)):
        # Odd-length palindrome
        left1, right1 = expand(i, i)

        # Even-length palindrome
        left2, right2 = expand(i, i + 1)

        if right1 - left1 > end - start:
            start, end = left1, right1

        if right2 - left2 > end - start:
            start, end = left2, right2

    return s[start:end + 1]
