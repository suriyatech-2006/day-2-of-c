Problem: Remove Duplicates While Preserving Order

Given a string, remove duplicate characters while keeping the first occurrence of each character in the original order.

Examples:
- "programming" -> "progamin"
- "banana" -> "ban"

Requirements:
- Preserve the original order.
- Treat uppercase and lowercase characters as different.
- Do not sort the characters.
- Aim for O(n) time complexity.

Expected concepts:
- Strings
- HashSet / set
- Frequency / order tracking

Approach:
Use a set to store characters already seen. Add a character to the result only when it has not appeared before.

Time Complexity: O(n)
Space Complexity: O(n)

Python Solution:

def remove_duplicates_preserve_order(s):
    seen = set()
    result = []

    for ch in s:
        if ch not in seen:
            seen.add(ch)
            result.append(ch)

    return ''.join(result)
